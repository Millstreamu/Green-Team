GREEN TEAM V55 — MAC TEST

Node is already installed if you ran V31. You do not need to install it again.

1. In the old Terminal window, press Control+C to stop the old game.
2. Unzip this download. The new folder is green-team-v55.
3. If you played V36, V37, V38, V39, V40, V41, V42, V43, V45, V46, V47, V48, V49, V50, V51, V52, V53 or V54, copy its whole data folder into green-team-v55 BEFORE starting. This keeps your home and goblins.
4. In Terminal type cd followed by a space. Drag green-team-v55 into Terminal and press Return.
5. Type npm ci and press Return. Wait for it to finish.
6. Type npm start and press Return.
7. Open http://localhost:8080. You start on the HOME SCREEN, with your goblin and level.
8. Create a lair with a name. Its join code is shown above the game.
9. Open a second tab and join using that same lair name and code. Refresh any old tabs.

EXISTING SAVE: your old home is preserved as Original Lair. Open the Private server admin link from Terminal, select Original Lair and copy its join code. Join from the home screen using that name/code. A backup is made before migration.

Keep Terminal open while playing. Control+C stops the server.

TEST: after joining the same lair, board both goblins, explore the same dungeon, hold E to search, release E and press again to collect. Tab opens sack; click to rearrange, R rotates, E drops held loot for a friend. Everyone gathers at the secret tunnel and presses E to leave together.

GEAR: Tab opens the sack. WASD or clicking selects gear; E equips. For snares, WASD aims without walking, release E then hold E for one second to place. Esc cancels. Step clear to arm. For smoke, equip then press Space. At home, free test gear is in the collapsed Debug supplies section of the stash/workbench.

DANGER: guards can chase either goblin. Three hits down you and spill your sack. Hold E half a second beside a hiding barrel; E exits. One goblin per barrel. Every three guard alerts bring another guard.

RESCUE: pack a Packed Lunch from the stash/workbench Debug supplies before leaving. Near a downed teammate, hold E for2seconds to restore1health. The lunch is spent only if you finish. Move, release E or take damage to cancel.

Guards carry downed goblins to the closest cage if no standing goblin is visible. You can follow behind a carrying guard, even close behind. Walk into its forward vision cone and it drops its captive to chase you. At a cage, hold E for3seconds to free a teammate to1health without using lunch. Smoke/snare the jail guard or coordinate a distraction. Pick spilled loot back up normally.

Only standing goblins gather at the tunnel. Restored goblins count again. Packed Lunch crafting cost is not chosen yet; use test supplies. Successful escapes now award personal XP to everyone who departed. The solo play.html is still separate. The shared lair now saves automatically in data/home.sqlite.

Close and reopen the browser: use the Goblin selector to choose an existing goblin. A second tab using an already-connected goblin gets a new goblin for testing.

Restarting during a dungeon run loses that run’s carried supplies and loot. Lair stock stays safe. Earned XP and unlocks save with your shared home.

V55 LOCKED TREASURE ROOMS
Search containers for a guaranteed treasure key outside the locked room. It takes one sack square and can be dropped for a teammate.

GREEN TEAM V38 — MAC TEST

Node is already installed if you ran V31. You do not need to install it again.

1. In the old Terminal window, press Control+C to stop the old game.
2. Unzip this download. The new folder is green-team-v38.
3. If you played V36 or V37, copy its whole data folder into green-team-v38 BEFORE starting. This keeps your home and goblins.
4. In Terminal type cd followed by a space. Drag green-team-v38 into Terminal and press Return.
5. Type npm ci and press Return. Wait for it to finish.
6. Type npm start and press Return.
7. Open http://localhost:8080 in two browser tabs. Refresh any old tabs.

Keep Terminal open while playing. Control+C stops the server.

TEST: board both goblins, explore the same dungeon, hold E to search, release E and press again to collect. Tab opens sack; click to rearrange, R rotates, E drops held loot for a friend. Everyone gathers at the secret tunnel and presses E to leave together.

GEAR: Tab opens the sack. WASD or clicking selects gear; E equips. For snares, WASD aims without walking, release E then hold E for one second to place. Esc cancels. Step clear to arm. For smoke, equip then press Space. At home, free test gear is in the collapsed Debug supplies section of the stash/workbench.

DANGER: guards can chase either goblin. Three hits down you and spill your sack. Hold E half a second beside a hiding barrel; E exits. One goblin per barrel. Every three guard alerts bring another guard.

RESCUE: pack a Packed Lunch from the stash/workbench Debug supplies before leaving. Near a downed teammate, hold E for2seconds to restore1health. The lunch is spent only if you finish. Move, release E or take damage to cancel.

Guards carry downed goblins to the closest cage if no standing goblin is visible. You can follow behind a carrying guard, even close behind. Walk into its forward vision cone and it drops its captive to chase you. At a cage, hold E for3seconds to free a teammate to1health without using lunch. Smoke/snare the jail guard or coordinate a distraction. Pick spilled loot back up normally.

Only standing goblins gather at the tunnel. Restored goblins count again. Packed Lunch crafting cost is not chosen yet; use test supplies. Successful escapes now award personal XP to everyone who departed. The solo play.html is still separate. The shared lair now saves automatically in data/home.sqlite.

SAVE TEST: put supplies in the stash and pack a real item into a goblin’s sack. Stop with Control+C, run npm start again in THIS same folder, and refresh both tabs. Check the items and gold survived. Close and reopen the browser: use the Goblin selector to choose an existing goblin. A second tab using an already-connected goblin gets a new goblin for testing.

Restarting during a dungeon run loses that run’s carried supplies and loot. Lair stock stays safe. Earned XP and unlocks save with your shared home.

IMPORTANT FOR FUTURE UPDATES: stop the server, then copy the whole data folder from this game folder into the next version’s folder before starting it. Do not throw away data: it contains your shared home. Back it up with the server stopped. V36/V37 saves work directly in V38. No new database software needs installing.

XP TEST: escape with valuables. Each departed goblin gets the same XP:1XP per gold from recovered valuables. Waiting arrivals get none. Downed/caged/offline teammates still receive the team reward. Failed or empty runs give no XP; materials, gear and debug supplies give none.

At the campfire, buy Quick Fingers for30XP (+10% search speed). At the workbench, buy the smoke recipe for50XP, then craft using shared materials. Unlocks are personal, not shared. Restart and check your remaining XP and owned upgrades survived. Repeated extraction/reconnection cannot pay the same run twice.

SERVER ADMIN: after npm start, Terminal prints a second link labelled Private server admin. Open that WHOLE link to manage the saved home. It is separate from the game page and changes on every restart. Use it only on the server computer.

You can back up/restore, set gold/materials/gear or one goblin’s XP, reset shared stock, reset one goblin or all progress, and end a stuck run. Every change makes a backup first. Reset/restore buttons ask for confirmation. Goblin identities stay so your browser can keep reconnecting. Edits require no active run; End run discards that run's carried loot/supplies and awards no gold/XP. Waiting sacks stay safe.

ADMIN TEST: click Make backup now, set one goblin's XP to80, check the game updates, then select that manual backup and Restore. Backups live in data/backups and stay when you reset progress. Copy the whole data folder for future updates. More details in docs/server-admin.md.

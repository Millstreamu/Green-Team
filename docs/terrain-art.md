# Proplet Human terrain — V45

User supplied GreenTeam-tileset.png and GreenTeam-tileset.json, and confirmed the intended reuse: top-right mirrors wall_corner_top_left; both bottom corners use wall_bottom_horz. The original five-tile32×32 image and JSON are copied unchanged into assets/human/ with their original filenames. No atlas repacking or new painted tiles.

src/terrain-art.js registers the pair, loads JSON and Image once during renderer setup and validates dimensions/columns/count/padding/spacing, Human tags, tile kinds, indices and frame bounds. The manifest supplies all source rectangles, including index4 on the second row. load/decode/validation failure reports a console warning and falls back to existing temporary art. Source image filenames are constrained to the registered pair. A future asset registry/editor can extend this; no upload/import UI is added in this slice.

Mapping follows adjacent walkable floor: floor uses floor; floor below a wall selects wall_top_horz, floor above selects wall_bottom_horz, floor to right/left selects wall_vert or its horizontal mirror. Upper outside corners use wall_corner_top_left or its horizontal mirror; lower outside corners both use wall_bottom_horz unchanged. A wall with floor on two adjoining lower sides uses the top-corner piece; complicated narrow intersections use the same deterministic five-piece precedence. New inner-corner/cap sprites can be considered after visual playtesting; no other wall shapes were invented. terrainTile never modifies world.tiles. JSON collision kinds are asset descriptions, not a replacement for server floor validation.

src/render.js uses the atlas only for world.job.jobId=manor outside the lair, in solo and online. Source32px tiles render into existing CONFIG.tile24px cells with smoothing disabled, preserving camera scale, sprite size, grid placement, reach and collision. Canvas save/translate/scale/restore mirrors art locally without changing later actors/UI. Furniture/doors/guards/minimap/builder schematic remain unchanged. Assets are not fetched per frame. Other architectures retain the existing temporary floor/wall drawing.

Server static whitelist explicitly exposes only the two new assets (plus previous public files); JSON receives application/json and PNG image/png. SQLite/backups/server source stay private. scripts/build.mjs embeds the PNG and JSON as data URLs in play.html; Image and fetch(data URL) work without a local server. The original copied assets are also included in the normal download. No runtime dependency, save migration, new balances or geometry changes.

Verification includes manifest frame validation, spacing/padding, all edge/corner/mirror mappings,40 generated-map tile classifications without mutation, actual renderer selection/load-once/fallback, real HTTP asset byte/content-type checks and existing solo/online event flows loading the actual manifest. Native Canvas renders of the real game renderer were visually inspected for Human terrain and Dwarf placeholder separation. This is not rendered browser automation; Chromium is unavailable. Standalone embedded data is decoded/compared with originals and bundle syntax checked. Human playtest: START-HERE.txt.


## V46 inside joins and corridor mouths

User screenshot seed2828433373 exposed a V45 rule error: choosing one full tile discarded vertical support whenever floor above selected the bottom strip (whose lower24pixels are transparent), and the diagonal outside corner was also selected when two adjacent cardinal floor directions described an inside join. Corrected terrainTile to reserve diagonal art for outside corners. Added terrainLayers composing existing source frames: side body beneath bottom caps, vertical quarter-width trim on horizontal inside joins, and mirrored half-width support for two-sided thin wall strips. Crop rectangles remain within the original frame and retain one-to-one source/destination portions. No art modifications, new assets, geometry/collision, or save changes. Original top/right mirroring and shared bottom outside corners remain.

Pure-rule regression tests cover both opening directions,16cardinal masks/crop bounds and the actual reported seed. Native Canvas alpha checks with the real PNG confirm all14side/top exposure masks fill the wall square; the intentional bottom-only8pxrim remains unchanged. Actual renderer before/after scenes of the reported seed were visually inspected: black gaps at corridor mouths are closed and diagonal inside seams are square.
